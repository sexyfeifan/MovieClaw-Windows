## 仍存在的差异与外部条件

- Mac 账号面板可直接跨服务器选已保存账号；Windows 当前先选择服务器，再切该服务器的账号。两端凭证仍按服务器隔离，Windows 尚未提供统一跨服务器账号面板。
- Mac 使用系统 SwiftUI/AVPlayer/AetherEngine，Windows 使用 WebView2/mpv。系统玻璃、原生菜单与最终 HDR/Dolby 输出没有逐像素或引擎等同承诺。
- Windows 原盘提供服务端主影片取流/降级；菜单、多角度、加密光盘及 DVD 位图字幕降级不在当前支持范围。按用户要求暂不进行无资源的实机验收。
- 本轮不部署 NAS。旧 NAS 的扫码配对仍需 Windows 设备能力及审批路由，见 `docs/deployment/windows-pairing.md`。
- 物理干净 Windows 10/11 无 WebView2 安装、多显示器 DPI、音频直通、不同 HDR/Dolby 显示设备、长时间稳定性和同条件 Mac 性能仍需对应设备。CI 的安装、导入与离线载荷验证不能替代这些物理测试。

完整性边界：以上功能按源码、自动化及本地实测分别核验；未将 CI fixture 当成 NAS 扫码成功、原盘成功或所有硬件输出成功。
