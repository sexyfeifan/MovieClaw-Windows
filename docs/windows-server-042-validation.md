# Windows 1.1.0 测试版：服务器 0.42 兼容

本轮以 Windows 1.0.3 后续开发分支为基础，同步 MovieClaw 上游提交 `1b73cb1de9c1f043649545372daac7be26dcc7b0`，对接服务器 0.42 的公开协议。上游同步与 Windows 功能修改分成独立提交，便于核对来源。

## 已实现的行为

| 功能 | 行为及边界 |
| --- | --- |
| 动态插件导航 | 登录后从 `/ui/apps` 读取当前账号可见且允许加入导航的插件，遵循 `nav.hidden` 和插件项排序。不要求安装映迹，也不内置任何插件包。返回前台或网络恢复时刷新；空清单、卸载和权限收回均移除对应入口。 |
| 映迹兼容 | `watch-friends` 显示服务器提供的页面，由该插件管理好友、记录和隐私。仍安装旧 `watch-presence` 的服务器保留原有观看动态界面；插件不可用时隐藏旧按钮。 |
| 插件窗口 | 每个窗口使用独立的本机回环地址和临时会话；服务器凭据留在 Rust。只允许打开服务器声明的页面目录，离开账号后关闭窗口和请求。插件窗口不获得主窗口的原生指令权限，关闭插件不退出播放器。 |
| 自动跳过 | 服从会话中的账号偏好。广告、预告及已经学习的本剧片头自动跳过；未知片头、片尾和剩余不足 3 秒的片段保留手动操作。手动跳片头可学习本剧偏好；反馈提供撤回，自动跳过片头的撤回会回到原位置并关闭该剧自动跳过。保存失败不伪装成功。 |
| Windows 原生设备登录 | 配套服务端增加 `windows` 设备类型及能力声明。支持密码、配对、设备替换、注销和改密失效。旧服务器继续 Cookie 登录，并说明配对需要服务端支持。 |
| 内外网地址选择 | 从认证后的服务器地址簿获取实例与主机公钥。先匿名验证候选地址的 Ed25519 挑战签名，再携带凭据；优先探测内网。账号和凭据仍归属原始服务器地址。媒体 Range、播放列表和插件请求均使用同一选路机制。网络错误时可为只读请求重选一次，写入操作不会自动重放。Secure Cookie 不会发送到 HTTP 地址。 |

地址探测结果最多缓存 5 分钟；登录后、返回前台、网络恢复及连接错误时触发刷新。地址切换作用于后续请求，不主动中断已经建立的播放流。没有地址簿或证明能力的旧服务器保留手动地址。

## 验证方式

本地执行 JavaScript 合约测试、真实 HTTP 与浏览器 DOM 测试、浏览性能样本，以及登录设备、配对、地址证明、插件网页、片段和账号权限相关服务端测试。Windows 原生编译、Rust 本机 HTTP 测试、WebView2 窗口隔离、安装卸载、打包及进程/CPU 解码基线交给 Desktop CI。

`server-features.spec.cjs` 覆盖空插件清单、动态安装卸载、导航授权和隐藏、标签注入、账号切换晚到响应、映迹入口、广告及片头的跳过与撤回，以及设置保存失败后的恢复。

原生测试使用本机 HTTP 服务验证签名、错误实例拒绝、Range、并发探测合并、切换时尚未结束的播放列表、写入不重放，以及插件窗口会话的来源校验与账号失效。Windows 包内的诊断模式还会创建真实 WebView2 插件页面，尝试调用主窗口原生指令；只有全部被拒绝才能通过安装包冒烟测试。

最终发布正文提供具体提交、构建号、Actions 链接及校验值。构建完成之前，不把编译检查或浏览器模拟当成 Windows 真机验收。

## 服务端配套

Windows 安装包不会修改用户的服务器。原生设备登录需要服务器包含本轮 `auth.py`、`schemas/auth.py`、`services/login_devices.py` 的兼容补丁；无需数据库迁移。服务器更新前可继续使用既有登录方式。插件导航、映迹、自动跳过和地址簿均使用服务器已有能力。

随测试版提供针对上述上游基线的独立补丁。应先检查补丁能否干净应用，并保留服务端当前镜像或源码以便回退；不要覆盖用户已有定制。当前 NAS 不作为本轮已部署服务端补丁的证据。

## Windows 真机验证清单

- [ ] 安装升级后保留服务器地址和现有账号，旧 Cookie 登录仍可用；配置目录没有明文令牌。
- [ ] 未装插件的服务器无残留入口；安装或卸载插件后切回应用，导航和设置页随之更新；成员权限与管理员保持隔离。
- [ ] 映迹页面可读取记录、管理好友及隐私；关闭窗口不退出主程序；切换账号后旧窗口关闭。安装了其他插件时，也验证各自页面和快捷入口。
- [ ] 有标记的影片正确跳过广告、预告和学习过的片头；撤回位置正确，跨集及重启后的账号偏好保持一致；设置保存失败有明确反馈。
- [ ] 服务端补丁部署后，Windows 密码登录和扫码配对在设备页显示 Windows 类型；注销、换账号、改密及时生效。
- [ ] 同一服务器从家中 Wi-Fi 切换到外网，再返回内网；验证海报、映迹、直放及 HLS 均能继续请求，拖动进度后的 Range 正常，写入没有重复执行。
- [ ] 实际 GPU 的 HEVC/AV1、HDR/杜比视界、音频直通、ASS/PGS 字幕、系统媒体键、DPI、多显示器和休眠恢复。

托管 Windows VM 的 CPU 解码及进程测试不能证明实际显卡画质、HDR 输出或与 macOS 同等硬件性能。
