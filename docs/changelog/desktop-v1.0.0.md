# MovieClaw Windows 1.0.0

连接 MovieClaw 服务器，在 Windows 上浏览媒体库、搜索并播放电影与剧集。

- **安装版**：下载 `MovieClaw-Desktop-1.0.0-Setup-x64.exe`，安装后输入服务器地址并登录。
- **便携版**：解压 `MovieClaw-Desktop-1.0.0-portable-x64.zip`，运行 `movieclaw-desktop.exe`；系统需已有 WebView2。
- **系统**：Windows 10/11 x64。安装版包含播放器及 WebView2 离线安装组件，无需额外开发工具或解码器。
- **更新**：设置中的“检查更新”支持新版本和同版本的新构建。

侧栏可收缩；播放支持字幕、音轨、倍速、画中画、实时速度和播放信息。双击视频或按 F 切换全屏，画幅可选择保持原比例或填满屏幕。
