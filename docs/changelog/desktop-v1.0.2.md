# MovieClaw Windows 1.0.2

连接自己的 MovieClaw 服务器，在 Windows 上浏览媒体库、播放电影与剧集。

- 安装：下载 `MovieClaw-Desktop-1.0.2-Setup-x64.exe`，安装后输入服务器地址并登录。
- 发现：浏览 TMDB / 豆瓣作品、搜索和筛选，查看详情并订阅影片。
- 我的订阅：查看追踪日程、下载与入库进度，管理季集范围和订阅。
- 两个新入口默认关闭，可在“设置 → 导航入口”分别开启；功能以服务器接口及账号权限为准。
- Windows 10/11 x64。安装版包含 mpv 播放器与 WebView2 离线组件，无需安装开发工具或额外解码器。便携版要求系统已有 WebView2。
