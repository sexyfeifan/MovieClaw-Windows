# MovieClaw Windows 1.0.1

连接 MovieClaw 服务器，在 Windows 上浏览媒体库、搜索并播放电影与剧集。

- **安装版**：下载 `MovieClaw-Desktop-1.0.1-Setup-x64.exe`，安装后输入服务器地址并登录。
- **便携版**：解压 `MovieClaw-Desktop-1.0.1-portable-x64.zip`，运行 `movieclaw-desktop.exe`；系统需已有 WebView2。
- **系统**：Windows 10/11 x64。安装版包含播放器及 WebView2 离线安装组件，无需额外开发工具或解码器。
- **字幕**：详情页可选择版本、音轨和字幕。管理员可使用服务器上的参考字幕生成单语或双语 AI 字幕，查看进度、取消和重试；PGS OCR 取决于服务器能力。服务器需配置 AI 模型，无参考字幕的语音转写暂不支持。
- **播放**：左右方向键前进或后退，上下方向键调整音量；双击视频或按 F 切换全屏。控制器显示当前音量，画幅可选择保持原比例或填满屏幕。
- **更新**：设置中的“检查更新”支持新版本。扫码登录入口暂时隐藏。
