# MovieClaw for Windows 1.1.0 测试版

本版连接 MovieClaw 0.42，补齐动态插件入口、映迹网页与本服影片链接、自动跳过和撤回，以及经过服务器身份证明的内外网地址选择。

- 插件入口来自当前账号的服务器插件清单。未安装或没有权限时隐藏；安装、卸载后切回应用会刷新。没有插件也可以正常浏览与播放。
- 映迹使用服务器已有网页管理好友、记录及隐私；观看链接回到 Windows 播放器，并重新核对片源权限。
- 广告、预告和学习过的片头按账号偏好自动跳过，支持撤回和手动开关。
- 服务器地址先验证实例和签名，再携带登录凭据。媒体 Range 和 HLS 使用同一选路机制；写入不会因网络错误自动重复提交。
- Windows 原生设备登录与配对需要配套服务端补丁。未部署补丁时继续现有 Cookie 登录；安装包不会自动改动服务器。

下载带构建号的安装版 ZIP，解压后运行其中带括号构建号的 EXE。兼容 EXE 与便携版继续保留；最终发布提供提交号、构建号和 SHA-256。

此为托管 CI 验证的测试版。安装包可能未签名。真实显卡的 HDR、音频直通、DPI、多显示器、休眠及跨网络播放仍需 Windows 真机验证。

完整行为和清单见 [Windows 验证说明](../../../docs/windows-server-042-validation.md)。
